# Калькулятор силы в Google Таблицах

## Генерация CSV

```bash
npm run export:power-sheet
```

Создаётся файл [`power-calculator-sheet.csv`](./power-calculator-sheet.csv) с **формулами** в колонке B, пояснениями в C (в блоке «РАСЧЁТ») и сверкой с Node в D.

## Формат файла (RU / Excel)

- **Разделитель полей в CSV:** точка с запятой (`;`)
- **Дробная часть в числах и формулах:** запятая (`,`)
- **Разделитель аргументов в формулах:** `;` (например `=MAX(0;B5)`)

## Импорт

### Microsoft Excel (русская локаль)

1. **Данные → Из текста/CSV** → выбери `power-calculator-sheet.csv`.
2. Кодировка: **UTF-8**.
3. Разделитель: **Точка с запятой**.
4. Загрузить.

Или открой файл двойным щелчком — если Excel уже настроен на `;` как разделитель списка, колонки встанут сами.

### Google Таблицы

1. **Файл → Импорт → Загрузка**.
2. Разделитель: **Точка с запятой** (не запятая).
3. Локаль таблицы: **Россия** (или другая с `,` как десятичной).

## Как пользоваться

| Колонка | Назначение |
| --- | --- |
| A | Подписи шагов |
| B | Ввод статов (Attack … Thorns), конфиг, дальше — формулы |
| C | Подсказки к конфигу; в блоке «РАСЧЁТ» — кратко, что считает строка |
| D | Сверка с Node (только ключевые строки; не обновляется после смены статов) |

Меняй статы и блок конфига. Эталонный противник: `oppAttack`, `oppArmor` (= `playerBase × S`). Номера строк печатаются в консоли после `npm run export:power-sheet`.

## Сверка с симулятором

Стартовый пример в CSV: **60 / 200 / 30** (блок «ВВОД СТАТОВ»). Колонка **D** — сверка с Node для этих же цифр.

Для **25 / 100 / 10** (как `playerBase`): **oppAttack** = 25, **oppArmor** = 10, **СИЛА** ≈ 44,71.

Сверяй колонку D с B в тех же строках после смены статов.

Если формулы не считаются:

- Проверь, что импорт использовал **`;`** как разделитель столбцов, а не запятую.
- Убедись, что `=MAX(0;B5)` не превратилось в текст (колонка B должна пересчитываться).
- Локаль Windows/Excel: десятичный разделитель **запятая**, разделитель списков **точка с запятой**.

## Обновление после изменения кода

Перезапусти `npm run export:power-sheet` и импортируй CSV заново (или обнови конфиг вручную по `src/battle/config.ts`).

Структура ячеек зафиксирована в `scripts/export-power-sheet-csv.ts` — при смене layout перегенерируй файл.
